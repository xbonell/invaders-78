# Low-poly render backend (stub)

Not implemented in Phase A. See the design spec:

[`docs/superpowers/specs/2026-08-05-arcade-framework-boundaries-design.md`](../../../../../docs/superpowers/specs/2026-08-05-arcade-framework-boundaries-design.md)

A future `LowPolyRenderBackend` implements the same `RenderBackend` contract as
`VoxelRenderBackend` — R3F scene subtree + event FX — using faceted / extruded
meshes inspired by classic 2D bitmaps instead of voxel cubes.
